# 大实验

**基础知识**
- 频数向量：能从每行交易生成长度为 d 的计数向量
- 相邻数据集：指两个只相差一个用户的数据集
- 隐私预算$\epsilon$：区分相邻数据集的代价/难度
- 敏感度：判断删除一个用户最多改变多少
  - 1.每个用户只贡献一个商品->敏感度=1
  - 2.一个用户可以购买多个商品->敏感度=L
- Laplace：实验一可信第三方的场景
  - 噪声可能为负数，可能和真实场景不符合
- 本地差分隐私：实验二无可信第三方场景，用户先加噪声再上传
- GRR：计算两个概率分布，通过计算概率来让上传的有噪声数据能够成功还原成真值加入到新的信息中
- UE：把商品编码成独热编码，逐位扰动

**实验流程**
- 场景一：可信第三方与 Laplace 机制
  - 用户把原始购买记录交给可信服务器；
  - 服务器可以看到所有人的真实记录；
  - 服务器计算准确频数；
  - 服务器只在最终发布时加噪声。
- 场景二：无可信第三方与本地差分隐私
  - 用户原始商品x
  - 用户本地随机扰动
  - 上传y或比特向量
  - 服务器聚合
  - 反演得到频数估计

**实验框架**
- 公共阶段：读取交易数据并计算真实频数
  - 目的：构造真实频数，是后续实验要用的（加工后的）数据
  - 分析：用户数n，商品数d，每个用户购买商品数
  - 实验：读取每行交易，统计真实频数
  - 结果：获得频数频数向量
- 实验
  - 实验一：集中式差分隐私（DP）【可信第三方】👉Laplace带噪声频数
    - 目的：服务器可以得到真实原始数据，但是发布时需要保护真实信息
    - 分析：相邻数据集定义、频数查询敏感度
    - 实验：使用Laplace方法加入噪声
    - 验证：在不同超参$\epsilon$下，误差(MSE)如何变化
    - 结果：不同超参下的MSE大小
    - 理论预期：
      - $\epsilon$越大，噪声越小
      - MSE总体下降
      - 若敏感度增大，MSE会明显增大。
  - 实验二：本地DP【不可信第三方】👉UE频数估计/GRR频数估计
    - 目的：服务器无法得到真实原始数据，但是发布时需要保护真实信息
    - 分析：多商品用户如何转换成本地机制输入、扰动概率 p,q
    - 实验：每个用户在本地加上扰动/噪声，再上传结果
    - 验证：1.聚合和反演后能否估计真实频数；2.在不同超参$\epsilon$下，误差(MSE)如何变化
    - 结果：不同超参下的MSE大小
    - 理论预期：
      - $\epsilon$越大，p和q越接近
      - MSE总体下降
      - 若敏感度增大，MSE会明显增大。
- 统一比较：MSE
  | 项目 | 内容 |
  | --- | --- |
  | 目的 | 比较不同信任模型下的隐私—可用性差异 |
  | 分析 | (\varepsilon)、信任模型和机制类型如何影响MSE |
  | 实验 | 将两个机制的结果整理到同一张表或曲线图 |
  | 验证 | 是否总体呈现“(\varepsilon) 增大、MSE下降”的趋势 |
  | 结果 | 至少两条 (\varepsilon)-MSE 曲线或对应表格 |
